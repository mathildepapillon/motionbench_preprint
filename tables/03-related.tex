Prior work develops dependence-aware Shapley attribution, temporal and grouped player definitions, and explanation-evaluation tools. MotionBench-XAI studies how these choices interact in a common evaluation protocol for spatiotemporal data, comparing imputers and player sets against reference explanations defined for the corresponding cooperative games.

\paragraph{Dependence-aware and temporal Shapley attribution.}
In the usual marginal-background implementation of KernelSHAP~\citep{lundberg2017unified}, missing features are replaced using background values without conditioning on the observed features. When features are dependent, the resulting combinations can be implausible or off-manifold~\citep{frye2021shapley}. Approaches to conditional Shapley estimation include empirical and copula-based conditioning~\citep{aas2021explaining,aas2021vineexplaining}, conditional inference trees~\citep{redelmeier2020explaining}, and variational conditioning~\citep{olsen2022using} based on VAEAC~\citep{ivanov2018variational}. ManifoldShap instead restricts interventional evaluations to a specified domain of
validity~\citep{taufiq2023manifold}. A related approach studies transport-based paths for Aumann--Shapley attribution~\citep{zhang2026axiomatic}.

Temporal methods adapt the explanatory units and estimation procedures. TimeSHAP provides feature-, timestep-, and cell-level attributions~\citep{bento2021timeshap}; WindowSHAP groups temporal intervals~\citep{NAYEBI2023104438}; and other work develops temporal surrogates and time-consistent attributions~\citep{villani2022feature}. ShaTS studies multiple temporal and feature groupings~\citep{de2025shats}. GroupSegment-SHAP constructs joint variable-group and time-segment players using cross-variable dependence and temporal segmentation~\citep{kim2026groupsegment}.

\paragraph{Benchmarks and spatiotemporal applications.}
Existing evaluation resources provide different kinds of reference information (Table~\ref{tab:related_benchmarks}). CLEVR-XAI proposes spatial localization masks~\citep{arras2022clevr}, BAM uses controlled relative feature importance~\citep{Yang2019BenchmarkingAM}, and Quantus provides a toolkit of evaluation metrics~\citep{hedstrom2023quantus}.
XTSC-Bench and xaitimesynth include synthetic temporal data with known informative regions~\citep{hollig2023xtsc,baer2026xaitimesynth}. These localization references differ from numerical Shapley values for a
specified model and game. \citet{olsen2022using} provides the latter type of reference in tabular simulations with known conditional distributions. Applications to human action and motion use DeepExplainer with reference samples~\citep{auletta2023predicting,tempel2025choose}. ShapGCN additionally validates explanations using GCN-specific edge
perturbations~\citep{tempel2025explaining}. ECG analysis also employs gradient-based explanations~\citep{strodthoff2021ecg}.

MotionBench-XAI builds on these lines of work by studying spatiotemporal player sets, conditional coalition completion, and ground truth comparisons together under a common evaluation protocol. % for spatiotemporal structure.
